## 5. Generación de paquetes BOCA del problemset 2025

Repo de problemas: https://github.com/elsantodel90/tap-2025-problemset (clonado a `~/Desktop/personal-hq/tap-2025-problemset`).

### Pipeline (entendido leyendo `mpkg.py` y `box-manual.md`)

1. `git submodule update --init --recursive` → trae el tool `box` (en `problems/.box/`).
2. Por cada problema:
   - `box build` (desde `problems/<carpeta>/`) genera `build/tests/<n>/*.in` y `*.sol` corriendo el reference solution sobre los inputs del `attic/`.
   - `python3 mpkg.py <letra> --problem=problems/<carpeta> --output=packages` arma el `.zip` con el layout BOCA (`compare/`, `compile/`, `description/`, `input/`, `limits/`, `output/`, `run/`, `tests/`).
3. `mpkg.py` toma:
   - `boca/names.txt` para el `fullname` del problema.
   - `boca/times.json` para los time limits por lenguaje (C/C++, Java/Kotlin, Python).
   - `print/tap-simple-faz.pdf` como descripción (mismo PDF combinado para todos los problemas).
   - `judge/*.exe` como special judge si existe.

### Issue resuelto: `bits/stdc++.h` no existe en macOS clang

Apple-clang (default `g++` en macOS) **no incluye** `<bits/stdc++.h>` (es un header GNU/libstdc++). Eso hacía fallar el build de los problemas que sólo tienen referencia en C++:

- Solución: `brew install gcc` → instala `g++-15` y `gcc-15`.
- `box` lee `CXX`/`CC` del entorno. El script setea `CXX=g++-15 CC=gcc-15` automáticamente si los detecta.

### Resultado

⚠ **Importante:** BOCA por default limita el upload PHP a 2 MB. Antes de subir paquetes pesados (B, D, J, K son >9 MB) hay que aplicar el ajuste documentado en el README principal:


Y reiniciar la VM.
